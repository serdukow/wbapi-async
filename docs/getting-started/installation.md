# Installation

## Requirements

- Python 3.11+
- Token from [Wildberries Seller Portal](https://seller.wildberries.ru/)

## Install from PyPI

```console
pip install wbapi-async
```

Or with `uv`:

```console
uv add wbapi-async
```

## Development install

```console
git clone https://github.com/serdukow/wbapi-async.git
cd wbapi-async
uv sync --all-extras
```
