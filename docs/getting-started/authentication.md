# Authentication

## Getting a token

1. Register in the seller [personal account](https://seller.wildberries.ru/).
2. Go to the store settings and [create an API token](https://dev.wildberries.ru/en/docs/openapi/api-information#tag/Authorization/How-to-create-a-personal-access-base-or-test-token). The token will allow you to access the WB API.
