# Claude Code Instructions

## What this project is

Async Python client for the Wildberries Seller API. Pydantic-free — responses
are plain `ApiResponse` objects with attribute access. No generated method
classes, no type models. Just HTTP verbs + path.

```python
async with WbAPI(token="...") as api:
    orders = await api.get("/api/v3/orders/new", limit=10, next=0)
    print(orders.orders[0].id)

    supplies = await api.get_all("/api/v3/supplies")  # auto-pagination

    await api.post("/adv/v0/rename", body={"advertId": 123, "name": "new"})
```

## File structure

```
src/wbapi_async/
├── __init__.py          # public exports: WbAPI, WbAPIError, TokenValidationError,
│                        #   PaginationNotSupported, ApiResponse
├── api.py               # WbAPI class — get/post/put/patch/delete/get_all
├── type.py              # ApiResponse — dict-like wrapper with attribute access
├── method.py            # MethodDispatcher + _PATH_TO_BASE + _PATH_TO_LIMIT
│                        #   (AUTO-GENERATED section — do not edit between fmt: off/on)
├── exceptions.py        # WbAPIError, TokenValidationError, PaginationNotSupported
├── utils/
│   ├── token.py         # validate_token()
│   └── unofficial.py    # @unofficial decorator
└── client/
    └── session/
        ├── base.py      # BaseSession — httpx, rate limiting, 429 retry
        └── headers.py   # Headers plain class
```

## Auto-generated section in method.py

`_PATH_TO_BASE` and `_PATH_TO_LIMIT` dicts are between `# fmt: off` and
`# fmt: on` markers. Regenerated by codegen from WB OpenAPI specs.
**Do not edit that block manually.**

Codegen lives at [serdukow/wbapi-codegen](https://github.com/serdukow/wbapi-codegen).
CI runs daily, downloads specs from `https://dev.wildberries.ru/api/swagger/yaml/en/`
and opens a PR if paths changed.

## Safe to edit

Everything except the `# fmt: off` block in `method.py`.

## Key design decisions

- **URL resolution**: `resolve_url(path)` does prefix lookup in `_PATH_TO_BASE`.
  Dynamic paths like `/api/v3/supplies/WB-123/orders` resolve via parent prefix.
  Unknown path → `WbAPIError` with a link to `https://dev.wildberries.ru`.

- **Rate limiting**: `_PATH_TO_LIMIT` maps path → `(period_ms, limit, interval_ms, burst)`.
  `MethodDispatcher` builds `AsyncLimiter` instances shared globally by `(interval_ms, burst)`.

- **Pagination** (`get_all`): auto-detects cursor (`next` field) or offset (full page = 1000).
  Custom paginator via `paginator=` kwarg: `callable(response) -> (items, next_params | None)`.

- **ApiResponse**: wraps raw dicts/lists recursively. `result.fieldName` works,
  `result.unwrap()` returns raw data. No snake_case conversion — field names are
  exactly as the API returns them (camelCase).
